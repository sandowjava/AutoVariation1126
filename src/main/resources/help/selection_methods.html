Selection Methods

Basic Selection

To select objects in the template, click directly on the object you want to select. Selected objects will be highlighted with a selection border.

Multiple Selection

There are several ways to select multiple objects:

  • Shift+Click: Hold the Shift key while clicking on objects to add them to the current selection.
  • Ctrl+Click (or Cmd+Click on Mac): Click on a selected object to deselect it while maintaining other selections.
  • Marquee Selection: Click and drag to create a selection rectangle. All objects within or intersecting the rectangle will be selected.

Selection Groups

You can create and manage selection groups to quickly select commonly used sets of objects:

  1. Select the objects you want to group
  2. Right-click and choose "Save Selection Group" from the context menu
  3. Enter a name for the selection group

To use a saved selection group, open the Selection Group panel from the View menu and click on the group name.

Selection Filters

You can filter selections based on object properties:

  • Select by Color: Select all objects with the same color as the currently selected object
  • Select by Type: Select all objects of the same type
  • Select by Name Pattern: Select objects whose names match a specified pattern

Keyboard Shortcuts

The following keyboard shortcuts can help with selection tasks:

  • Ctrl+A (or Cmd+A on Mac): Select all objects
  • Escape: Deselect all objects
  • Tab: Cycle through objects
  • Shift+Tab: Cycle through objects in reverse order
