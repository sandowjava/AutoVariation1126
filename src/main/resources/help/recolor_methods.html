Recolor Methods

Basic Recoloring

To change the color of objects in your template, first select the objects you want to recolor, then use one of the following methods.

Color Palette

The color palette provides a quick way to apply predefined colors:

  • Select one or more objects
  • Click on a color in the palette to apply it to the selected objects
  • Right-click on a palette color to set it as the current fill or stroke color

Color Picker

For more precise color selection:

  1. Select the object(s) to recolor
  2. Click the Color Picker tool in the toolbar
  3. Use the color picker dialog to select your desired color
  4. Choose whether to apply the color to the fill, stroke, or both

Color Shifting

Color shifting allows you to adjust colors while maintaining relationships between them:

  • Hue Rotation: Shifts all colors around the color wheel by a specified angle
  • Saturation Adjustment: Increases or decreases color intensity
  • Brightness Adjustment: Makes colors lighter or darker

To use color shifting, select objects and use the Color Shift panel from the View menu.

Color Drag

The color drag feature allows intuitive color adjustment:

  1. Select the objects to recolor
  2. Enable Color Drag mode from the Tools menu
  3. Click and drag on the canvas:
    • Horizontal movement adjusts hue
    • Vertical movement adjusts brightness
    • With Shift key: Vertical movement adjusts saturation

Color Schemes

Apply color harmony rules to create cohesive color schemes:

  • Complementary: Colors opposite each other on the color wheel
  • Analogous: Colors adjacent on the color wheel
  • Triadic: Three colors evenly spaced around the color wheel
  • Split Complementary: A color and two colors adjacent to its complement

Access color schemes from the Color menu after selecting objects.
